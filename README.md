# DB · 豆包对话解析与无水印保存

一个单页 Web 应用：粘贴豆包（Doubao）App 分享出来的对话链接（`doubao.com/thread/...`），1:1 复刻还原手机端对话界面，并把对话中的图片 / 视频替换为**无水印版本**，支持单个保存与批量下载。

> 仅用于个人学习交流，请勿用于商业用途；所解析内容的版权归原作者所有。

## 功能

- **对话 1:1 复刻**：还原豆包手机端 UI——用户气泡右侧蓝色（#0066FF）、AI 气泡左侧灰色（#f4f4f4）、768px 栏宽、markdown 渲染（标题/列表/表格/代码块/引用）。
- **无水印媒体**：图片取 `image_ori_raw` 原图直链；视频走 fallback 接口取无水印源，H.265 自动转码 H.264（`/api/convert`）。
- **单个操作菜单**：点媒体弹出 放大 / 下载 / 复制链接 / 多选。iOS 走系统分享面板（可存相册），Android 走浏览器下载。
- **复制无水印直链**：复制的是图片/视频的原始直链（非对话链接），手势窗口内同步写入剪贴板。
- **多选模式**：长按媒体直接进入多选，顶部栏全选，底部批量分享 / 批量下载。
- **批量下载**：解析框下方「批量下载图片 / 批量下载视频」，网格预览勾选，打包 zip。
- **时间筛选**：按消息时间筛选 0.5h / 1h / 6h / 12h / 24h / 48h / 72h。
- **刷新恢复**：解析结果快照存 `sessionStorage`，刷新后零网络请求原样恢复。
- **下载文件名带时间戳**：如 `img_001_20260917_102525.jpg`、`video_001_20260812_140955_1280p.mp4`。

## 运行

```bash
python doubao_chat.py            # 默认 8766 端口
python doubao_chat.py 9000       # 自定义端口
```

浏览器打开 `http://127.0.0.1:8766`，粘贴分享链接点「解析」即可。

依赖：Python 3.8+，纯标准库（解析与媒体代理复用同目录的 `doubao_engine.py` / `doubao_web.py`）。H.265 转码需要系统安装 `ffmpeg`（可选，仅遇到 H.265 视频时使用）。

## 文件结构

| 文件 | 说明 |
|---|---|
| `doubao_chat.py` | 主程序：单页对话复刻 UI + 路由（端口 8766） |
| `doubao_engine.py` | 解析引擎：分享页递归 fn-args JSON → 结构化对话，兼容新旧版页面 |
| `doubao_web.py` | 媒体通道：`/proxy` 签名链接代理、`/api/video` 无水印视频、`/api/convert` 转码、`/api/zip` 打包 |

## 关键实现说明

- **手势窗口内分享**：页面在解析完成后即后台预取所有媒体 blob；点「下载」时直接使用缓存 Promise，`navigator.share` 仍在用户手势窗口内触发——解决 iOS / Android 点了没反应的问题。
- **签名链接时效**：豆包 CDN 直链带签名和有效期，全部经本地 `/proxy` 代理转发，避免跨域与过期问题。
- **空结果绝不缓存**：解析失败/空对话不写入缓存，避免刷新后拿到坏快照。
